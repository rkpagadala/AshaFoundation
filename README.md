An independent analysis of grant funding by [Asha for Education](https://ashanet.org/) chapters, broken down by Indian state, year and chapter.

> **Not affiliated with or endorsed by Asha for Education.** Data is derived from public project pages and contains no personal contact information. See [DATA_NOTICE.md](DATA_NOTICE.md) for sources, exclusions and licensing.

Instructions To Run:

1. Run ```ACTION=download python3 Download/cli.py download``` to download the data.
2. Run ```ACTION=analyze python3 Download/cli.py analyze``` to analyze the data.
3. Run ```streamlit run web/app.py``` to run the web app.

Deployed URL : https://ashaforeducationanalysis.streamlit.app/
